Como funciona

Tudo o que você precisa para construir, em um só lugar.

Modele o chassi, conecte a eletrônica e escreva o código. Depois aperte Run e veja seu robô se mover.

01 / CAD

Modele.

Desenhe o chassi, solte motores e rodas e encaixe tudo em uma bancada 3D de verdade. Cada peça tem medida, então o que você monta aqui é o que montaria na sua mesa.

MoverRotacionarEscalarExtrudarCortarSnap na grade
02 / ELETRÔNICA

Ligue os fios.

Parafuse um Arduino em cima, adicione um sensor ultrassônico e arraste os fios de pino em pino. Cada conexão fica visível — e o sensor só funciona se estiver ligado certo.

Arduino UNOESP32Ultrassônico HC-SR04Sensor IRSensor de gásSensor de corLDRDHT11OLED 128×64
03 / CÓDIGO

Programe.

Escreva o sketch em blocos ou em C++ e rode. A placa acorda, o sensor dispara e seu carrinho anda — com física de verdade decidindo o resto.

Programação em blocosC++ Arduino10 projetos prontosGravidade: Terra · Lua · Marte · Zero-G

FAQ

Perguntas respondidas.

É grátis mesmo?

Sim, completamente grátis. O RoboLab é a ferramenta da Academe Educação para levar robótica a qualquer escola.

Preciso baixar alguma coisa?

Não. Roda direto no navegador: Chrome, Edge, Firefox ou Safari. Use um computador, porque construir robôs grandes pede uma tela grande.

Estou no celular. Dá para usar?

O RoboLab foi feito para telas de computador, então ainda não funciona no celular. Abra no notebook ou no computador da escola.

O que eu consigo construir?

Qualquer robô que imaginar: rodas, pernas, braços, sensores, motores. Construção 3D livre, não kits prontos.

Quais linguagens de programação tem?

Duas: programação em blocos para começar e C++ de Arduino de verdade quando você estiver pronto. Os blocos escrevem o C++ para você.

O que é a Academe?

A Academe Educação leva tecnologia e IA para escolas. O RoboLab é a nossa oficina de robótica no navegador.
